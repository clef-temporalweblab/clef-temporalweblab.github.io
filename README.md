# TemporalWebLab 2027 website

Official website for **TemporalWebLab: Evaluating Recency and Change across the Web**, a pilot evaluation lab at CLEF 2027.

## Editing the site

- Page content: `index.html`
- Colours, typography, and layout: `assets/style.css`
- Mobile navigation and subtle interactions: `assets/main.js`
- Browser icon: `assets/favicon.svg`

The site uses plain HTML, CSS, and JavaScript, with no build tools or external framework required.

## Publishing

In the repository settings, open **Pages**, select **Deploy from a branch**, and choose the `main` branch and `/ (root)` folder.
