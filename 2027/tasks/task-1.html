Task 1 · Ordinal classification

Question Recency Requirement Estimation

Predict how soon the currently correct answer to a question may need to be updated.

Overview

Information changes at different rates. A live score may become outdated within minutes, while a historical fact may never require an update. This task asks systems to estimate the recency requirement of a question rather than answer it.

Campaign status: The task definition is established, while release links, final split sizes, and exact submission dates will be added when confirmed.

Input and output

Input

A natural-language question, with accompanying context where provided in the released dataset.

Output

Exactly one label from the twelve ordered recency classes.

Illustrative example

QuestionWho is the current president of the country?
PredictionA few years
InterpretationThe answer is expected to remain valid on a multi-year rather than permanent timescale.

Recency classes

The labels form an ordered scale from the most frequently changing information to information that is not expected to change.

The campaign dataset is derived from RecencyQA and covers questions with diverse expected update frequencies.

Evaluation

MetricPurpose
Macro-F1Primary metric; gives equal importance to every recency class.
Strict accuracyCounts only exact class predictions.
Tolerant accuracyAccepts predictions within one adjacent class.
Mean absolute ordinal distanceMeasures how far predictions are from the gold class.
Under-estimation rateTracks predictions that recommend less frequent updating than required.

Baselines

Planned starter systems include a majority-class baseline, supervised classification, ordinal classification, and zero- or few-shot language-model prompting.

Submission and participation

Teams will submit one valid label for every test question through TIRA. The current plan permits up to three runs per task, with one primary run identified for official reporting.

  • Teams may enter Task 1 without participating in Task 2.
  • Each run must use the released question identifiers and exact label spelling.
  • System descriptions should report training data, model, prompting or optimization method, and external resources.

Task 1 FAQ

Must systems answer the question?

No. The required output is the expected update interval, not the factual answer.

Is a neighbouring class accepted?

Macro-F1 and strict accuracy require the exact class. Tolerant accuracy additionally reports predictions within one adjacent class.

Can external models or data be used?

Permitted external resources will be defined in the final participation rules and must be documented.
